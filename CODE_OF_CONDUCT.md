# Code of Conduct

## Our Standards

This project is maintained as a professional, research-oriented open-source project.

Participants are expected to communicate clearly, respectfully, and constructively. Disagreement is acceptable. Personal
attacks, harassment, intimidation, discriminatory language, or disruptive behavior are not acceptable.

Examples of acceptable behavior include:

- reporting bugs with enough information to reproduce them;
- asking technical or scientific questions in good faith;
- giving constructive feedback on code, documentation, models, or assumptions;
- respecting different levels of expertise;
- keeping discussion focused on the project.

Examples of unacceptable behavior include:

- insults, harassment, threats, or personal attacks;
- discriminatory or exclusionary language;
- deliberately derailing technical discussions;
- publishing private information without permission;
- hostile comments about a person rather than their contribution;
- repeated low-effort or bad-faith interactions.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, documentation,
examples, and any other official project communication channels.

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, block users, or take other reasonable
action when behavior violates this Code of Conduct.

Enforcement decisions are made at the discretion of the maintainers to protect the quality, safety, and usefulness of
the project.

## Reporting

To report unacceptable behavior, contact the project maintainer through the contact information listed in the
repository.

Reports should include relevant links, screenshots, usernames, dates, and a concise description of the issue.

## Attribution

This Code of Conduct is adapted for a small scientific open-source software project and is intended to support clear,
professional, and constructive collaboration.
